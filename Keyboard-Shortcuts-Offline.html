Tips for learning shortcuts

Learn two or three a day

Do not try to memorise the whole list. Pick the shortcuts you need for your work and use them every day.

Start with the basics

Copy, cut, paste, undo, select all and save cover most daily jobs.

Keep your hands on the keyboard

Each time you reach for the mouse, ask yourself if there is a shortcut. This habit also improves your typing speed.

Use the Windows or Cmd key rules

On Windows most shortcuts use Ctrl. On Mac the same shortcuts usually use Cmd.

Download the cheat sheet

Keep this list on your phone with the offline file: download the keyboard shortcuts cheat sheet.

Shortcuts can differ slightly by program and version. If one does not work, check the menus of your program, where the shortcut is usually shown next to the command. To get faster at typing itself, read our beginner typing guide.

Frequently Asked Questions

What are keyboard shortcuts?

Key combinations that perform an action faster than using the mouse.

Which shortcuts should beginners learn first?

Copy, cut, paste, undo, select all and save: Ctrl + C, X, V, Z, A and S.

What is the Mac version of Ctrl?

The Command key, written Cmd, is used for most shortcuts that use Ctrl on Windows.

Do shortcuts work on a phone?

With a physical keyboard connected by OTG or Bluetooth, many shortcuts such as copy, paste and select all work in Android apps.

Do shortcuts help typing speed?

Yes. They save time when editing, so you finish work faster.

How can I learn shortcuts quickly?

Learn two or three a day, use them every day, and try the practice box on this page.

What does Ctrl + Shift + T do?

It reopens the last closed browser tab.

What is the difference between Ctrl + Z and Ctrl + Y?

Ctrl + Z undoes the last action and Ctrl + Y redoes it.

Are shortcuts the same in every program?

Many are the same, but some differ by program or version.

Where can I download this list?

Use the offline download on this page to keep the shortcuts without internet.
